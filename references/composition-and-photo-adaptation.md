# 构图测量与照片适配

## 归一化构图记录

查看实际公告图，记录画布 W、H 和宽高比。左上为原点；横向位置与尺寸除以 W，纵向除以 H，范围 0–1。肉眼估计需标为估计，不能虚报像素精度。每个年度独立分析，没有通用固定诺贝尔比例。

| 对象 | 必须记录 |
|---|---|
| 每位人物 | 可见肖像框 x/y/w/h、头顶、下巴、头高/H、眼线 y/H、肩线 y/H、中心 x/W、朝向、肩轴、裁切边缘 |
| 多人关系 | 左右顺序、中心间距/W、头高相对关系、重叠、姓名与人物中心对应 |
| 标题与年份 | 文字框 x/y/w/h、行数、对齐、字重、字形特征、字号/H |
| 姓名 | 各文字框、基线、字号/H、与标题字号之比、距肖像下缘间隔/H |
| 获奖理由 | 文字框、行数、行距/H、字号/H、引号和对齐 |
| 全局 | 四边留白、底部区域、背景色、黑白与金色分布、线条粗细、边缘及纸面笔触 |

头高指头顶到下巴，不能用整个肖像高度替代。身份引起的头发外轮廓差异可以保留，不为几何匹配改变脸型。字体无法确认时描述视觉特征，不虚报字体名。

## 照片适配

| 输入 | 处理 | 避免 |
|---|---|---|
| 全身照 | 以脸确定身份，按模板头高、眼线重绘头肩及衣领 | 完整身体缩进肖像区，导致头过小 |
| 半身照 | 重设头部尺度、肩线、肩轴与下缘裁切 | 沿用原照胸部占比和背景 |
| 头像 | 保留五官发型，补绘模板需要的肩颈、衣领及姿态 | 拉伸脸或头像填满整个人物框 |
| 多人输入 | 确认姓名与左中右映射，分别适配模板头高关系 | 混合身份、重复脸或擅自采用原站位 |

大幅转头可能使身份漂移。以模板姿态为目标，但看不出本人时优先修订身份。不要添加原获奖者的年龄特征、发型、眼镜或胡须。服装未指定时按参考范围补绘，不额外添加徽章装饰。

## 文字适配

锁定文字框与字号比例，再换行。中文和拉丁文字字宽不同，以实际视觉宽度匹配，不按字符数直接换算。不擅自删字、译名或改写理由。无法容纳时请求精简，确认后更新确切原文。保留信息层级，不机械复制旧姓名或官方机构颁奖措辞。

## 验收与停止

1. 身份：脸型、五官关系、发型及眼镜可辨识，没有被参考人物替换。
2. 构图：宽高比、人物数和顺序正确；对比头高、眼线、肩线、肖像框、裁切和间距。
3. 排版：文字区域位置、尺寸、字号关系、对齐、行距与留白贴合；逐字检查全部姓名、理由和标点。OCR 仅作辅助，仍需查看图片。
4. 绘画：比较参考实际线条、黑白块面、金色分布、边缘和纹理，不只检查是否黑金。
5. 清理：无旧姓名、额外人物、原画家签名或错误署名，无意外裁断或文字遮挡。

主要人物锚点和文字区域的位置/尺寸偏差目标约为画布对应维度的 3%。例如眼线差是 |y输出/H输出 − y参考/H参考|，头高差也以 H 归一化，不是相对头高的 3%。这不是模型保证，不用于每根线条。仅肉眼比较时写“视觉近似”，不提供伪精确百分比。身份和文字准确性不能为了几何误差让步。

首次生成后最多修订两轮。仍有错误文字或明显身份漂移时标为未通过，不能称为准确复刻；可交付最佳尝试并注明问题。

## 验证场景

安装或修改时检查下列决策覆盖情况；静态检查不能替代出图验收。有照片和工具后再生成，保留参考与结果对照。

- 同一人物全身、半身、头像配同一模板：身份一致，头高、眼线、肩线由模板决定。
- 单人、双人、三人：人数和姓名映射正确；人数不匹配先明确适配方案。
- 中文姓名、长拉丁姓名、长理由：保持层级，先换行，无法容纳则请求精简。
- 指定历史年度：使用该年度真实参考；缺失请求上传，不无声回退。
- 当年只发布部分奖项：默认采用最近完整年度；显式指定当年仅用已发布真实参考。
- 参考不可访问或不能传入图像工具：请求可用参考，不凭网页摘要生成。
- 模糊、遮脸或多人对应不明：先补充清晰照片或映射，不伪称身份验收通过。
